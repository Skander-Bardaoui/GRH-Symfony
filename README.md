## Overview

A Symfony human-resources management application covering employees, leave and HR administration. Built with Doctrine ORM and migrations, Twig templates and a modern asset pipeline.

## Highlights

- Employee and HR record management
- Leave and absence workflows
- Doctrine entities and migrations
- Role-based access for HR staff
- Docker Compose development environment

## Getting started

**Prerequisites:** PHP 8.2+, Composer, Node.js and a database.

```bash
composer install
npm install
# configure DATABASE_URL in .env
php bin/console doctrine:migrations:migrate
symfony server:start
```
